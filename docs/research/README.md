# Research notes

Exploratory reports on candidate data sources and layers, written before any spec. Each was
produced by a research agent that fetched the endpoints it cites on the date in the file name;
treat sizes, counts and availability as snapshots and re-verify before building.

- [Volcanoes](2026-10-17-volcanoes.md): GVP catalogue over WFS, USGS HANS alert levels, GeoNet, VAACs, thermal and gas products; a first-scope ingest.
- [Gravity anomalies](2026-10-17-gravity-anomalies.md): free-air, Bouguer and isostatic grids; one pre-projected raster per view.
- [Magnetic field](2026-10-17-magnetic-field.md): core field (WMM/IGRF) contours versus crustal anomaly rasters (EMAG2v3, NAMAG).
- [Space weather](2026-10-17-space-weather.md): NOAA SWPC JSON products after the 2026 changes, GFZ Kp, OVATION aurora grid; a polling plan.
