# Volcanoes Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Volcanoes page beside the earthquake page: GVP catalogue on the map, live USGS and GeoNet status, weekly-report entries, eruption history, nearby earthquakes.

**Architecture:** Reference data is generated into checked-in JSON served by the geo route; live status and reports are polled into two Postgres tables by jobs on the existing scheduler and served by a new route group. The web app gains a page switch, a volcano store, and a map built on a composable extracted from the earthquake map.

**Tech Stack:** Fastify, Drizzle, zod, Vue 3, d3-geo, Vitest, Testcontainers.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-10-17-volcanoes-design.md`.
- Branch `volcanoes`; PR to `main`; never commit to `main`.
- TypeScript strict, `.js` imports, no `as` for nullability, no `!`; 100% coverage on server, shared and web.
- Migrations generated by drizzle-kit, never hand-edited.
