# Field overlays: gravity and magnetic anomaly rasters under the map

Date: 2026-10-24. Sub-project: Front end (with a generator script). Status: approved, one PR with
a commit per task. Research: `docs/research/2026-10-17-gravity-anomalies.md` and
`docs/research/2026-10-17-magnetic-field.md`.

## Why

A geologist reading epicentres and faults wants the potential fields underneath: free-air
gravity picks out trenches, outer rises and seamounts; isostatic residual gravity picks out
basins, batholiths and range fronts; the crustal magnetic anomaly shows spreading stripes,
fracture zones and terrane boundaries. Both reports recommend the same shape: one raster per
field per view, rendered ahead of time in the app's own projections, drawn under the vector
layers, off by default, with a legend that names product, reduction or altitude, and vintage.

## Decisions

| Topic           | Decision                                                                                                                                                                                                                                                                                     |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Scope           | Crustal fields only: gravity anomaly and total-field magnetic anomaly. The core field (WMM declination contours) is on the backlog as a maybe.                                                                                                                                               |
| Control         | One `Field` select in the map toolbar: `none`, `gravity`, `magnetic`. One raster at a time, shared by every map page, in memory like the plate toggle (not in the route).                                                                                                                    |
| Gravity, global | Free-air anomaly: GMT mirror of Scripps v33, `earth_faa_06m_p.grd` (netCDF-4, 3600×1800, int16 with scale 0.025 and offset 300, mGal). Diverging ramp clipped at ±120 mGal.                                                                                                                  |
| Gravity, WC     | USGS conterminous-US isostatic residual (DDS-9, Simpson and Jachens): `isograv.gxf.gz`, 1300×768 nodes at 4 km in Albers equal-area (parallels 29.5 and 45.5, origin 0 / −96, NAD27 Clarke 1866), dummy −1e32, offshore values are free-air. Ramp ±80 mGal. Outside the grid is transparent. |
| Magnetic        | EMAG2v3 upward-continued to 4 km: GMT mirror `earth_mag4km_06m_p.grd` (same layout as the gravity grid, nT). Both views. Diverging ramp over equalised stops, since a linear ramp hides the spreading stripes; the legend says the ramp is equalised.                                        |
| Not in v1       | Hillshade, contours, a pointer readout, the 1 km USGS North America magnetic compilation, the 2′ tiles (JPEG 2000 on the GMT server).                                                                                                                                                        |
| Rendering       | One RGBA PNG per field per view at 2048 px wide, every output pixel inverted through the view's d3 projection and sampled bilinearly, so the raster aligns with the plate and fault paths. Pixels off the sphere, off the grid or on a dummy are transparent.                                |
| Where it lives  | `apps/web/public/fields/`: four PNGs and `fields.json`. Static files, so Vite serves them in dev and nginx from `dist/` in production. Generated by `pnpm --filter @tectonic/web geo:fields`, checked in, never hand-edited.                                                                 |
| Sources cache   | Downloads land in `apps/web/.cache/fields/` (gitignored) and are reused on later runs.                                                                                                                                                                                                       |
| Drawing         | `MapField.vue`: an SVG `<image>` the size of the frame, between the basemap land and the faults, opacity 0.6, `mix-blend-mode: multiply` on the light theme and normal on dark.                                                                                                              |
| Legend          | A ramp row for the field in force: the gradient, tick values with units, and a caption line (product, grid, altitude or reduction, vintage, source).                                                                                                                                         |
| Research docs   | The two reports are copied into `docs/research/` on this branch (with the index trimmed to them); the `research/data-sources` branch keeps the rest.                                                                                                                                         |

## 1. Shared types (`packages/shared/src/api.ts`)

```ts
export type FieldId = "gravity" | "magnetic";
export type FieldView = "global" | "wc";

/** One rendered raster and the legend that explains it. */
export interface FieldRaster {
  field: FieldId;
  view: FieldView;
  /** Path under the web root, e.g. "/fields/gravity-global.png". */
  src: string;
  width: number;
  height: number;
  units: string; // "mGal" | "nT"
  /** Ramp stops as [value, "#rrggbb"], ascending; the legend draws the gradient from them. */
  stops: [number, string][];
  /** Tick values to label on the ramp. */
  ticks: number[];
  /** True when the stops are histogram-equalised rather than linear. */
  equalised: boolean;
  /** "Free-air anomaly · Scripps v33 via GMT · 6′ grid · 2026". */
  caption: string;
  source: { name: string; url: string; doi: string | null };
}
export interface FieldsFile {
  generated: string; // ISO
  rasters: FieldRaster[];
}
```

`Json<T>` is not needed: this is already a JSON shape.

## 2. Generator (`apps/web/scripts/fields-cli.ts`, pure parts in `apps/web/src/lib/field-render.ts`)

### Pure module `field-render.ts`

```ts
/** A lon/lat grid, row 0 at the south edge, pixel-registered, lon from -180. */
export interface LonLatGrid {
  width: number;
  height: number;
  values: Float32Array;
} // NaN for no data
/** Bilinear sample at (lon, lat); NaN near a NaN neighbour or outside. Lon wraps. */
export function sampleLonLat(g: LonLatGrid, lon: number, lat: number): number;

/** A projected grid with its own inverse. */
export interface ProjectedGrid {
  width: number;
  height: number;
  values: Float32Array;
  /** Column and row (fractional) for a lon/lat, or null outside the grid. */
  locate(lon: number, lat: number): [number, number] | null;
}
export function sampleProjected(g: ProjectedGrid, lon: number, lat: number): number;

/** Ellipsoidal Albers equal-area forward projection (Snyder 1987, 14-1 to 14-12) for the USGS DDS-9 grid. */
export function albersForward(p: AlbersParams, lon: number, lat: number): [number, number];

/** Linear stops between -limit and +limit over a diverging ramp. */
export function linearStops(limit: number, ramp: readonly string[]): [number, string][];
/** Stops at the percentiles that split the finite values into as many bands as the ramp has colours. */
export function equalisedStops(values: Float32Array, ramp: readonly string[]): [number, string][];
/** Colour for a value: interpolated between the two enclosing stops, clamped at the ends. */
export function colourAt(stops: [number, string][], v: number): [number, number, number];

/** Renders width×height RGBA bytes: each pixel inverted through `invert`, sampled through `sample`, coloured. */
export function renderRaster(
  width: number,
  height: number,
  invert: (x: number, y: number) => [number, number] | null,
  sample: (lon: number, lat: number) => number,
  stops: [number, string][],
): Uint8Array;
```

The ramp is the same five-colour diverging set for both fields (blue, pale blue, near-white,
pale red, red) at reduced chroma so marker colours stay distinct; values exported as `RAMP`.

### Readers (in the CLI, not covered)

- GMT grids through `h5wasm/node`: datasets `lon`, `lat`, `z` (int16, `scale_factor`,
  `add_offset`, `_FillValue` −32768). `z[row][col]` with row 0 at latitude −90 + half a cell.
- GXF through a small parser: header keywords until `#GRID`, then `ROWS × POINTS` numbers in
  row-major order from the north-west origin (`#SENSE 1`), `#DUMMY` as NaN. `locate` uses
  `albersForward` with the header's parameters: `x = XORIGIN + col·4000`,
  `y = YORIGIN − row·4000`.

### Frames

The script imports `frameFor` from `src/lib/geo.ts` with the two region presets the server
serves (ids `global` and `wc`; the script carries copies of the preset bboxes because it has no
API). Output size: width 2048, height `2048 × frame.height / frame.width` rounded (global
1065, West Coast 1434). `invert(x, y)` maps an output pixel centre to frame coordinates
(`x × frame.width / 2048`) and calls `frame.projection.invert`; for the global frame a point is
also rejected when `projection(invert(p))` lands more than a pixel away, which drops the area
outside the sphere.

### Output

`public/fields/gravity-global.png`, `gravity-wc.png`, `magnetic-global.png`, `magnetic-wc.png`
through `pngjs` (RGBA, deflate level 9) and `public/fields/fields.json`. If a PNG exceeds
3 MB the script logs it; the plan then halves the width for that raster.

### Script

`pnpm --filter @tectonic/web geo:fields` = `node --import tsx scripts/fields-cli.ts`. Steps:
ensure cache dir, download each source if absent (`fetch`, streamed to disk), decode, render
the four rasters, write files, print sizes. `scripts/` is outside the coverage include and the
lint config covers it like the server's CLIs.

## 3. Front end

- `src/lib/fields.ts`: `type FieldChoice = "none" | FieldId`, `FIELD_LABELS`,
  `loadFields(api)` cached once (fetches `/fields/fields.json` through `fetch`, not the API
  client, since it is a static file; `resetFieldsCache()` for tests), `rasterFor(file, field,
view)`.
- `useMapView` gains `field: Ref<FieldChoice>` (default `none`), `fields: ShallowRef<FieldsFile
| null>` loaded on first non-none choice, and `fieldRaster: ComputedRef<FieldRaster | null>`
  for the current frame (`global` when the region has no bbox, else `wc`).
- `MapShell.vue`: a `<label>Field <select v-model="mv.field.value">` after the Quaternary faults
  picker, options from `FIELD_LABELS`; `<MapField v-if="mv.fieldRaster.value !== null"
:raster :frame />` after `MapBasemap`. Passes `mv.fieldRaster.value` to the legend.
- `MapField.vue`: `<image :href="raster.src" x="0" y="0" :width="frame.width"
:height="frame.height" preserveAspectRatio="none" class="field" />`. Styles: `.field {
opacity: 0.6 } [data-theme=light] .field, :root:not([data-theme]) .field at light {
mix-blend-mode: multiply }` following the theme rules already in `styles.css`.
- `MapLegend.vue`: `field?: FieldRaster | null`; when set, a row `.fieldrow` with a 160×10 svg
  gradient from the stops (`linearGradient`), tick labels under it, and the caption in muted
  text; `equalised` adds " · equalised ramp" to the caption display.
